At the moment following examples are included with the code

- 2-loop Gluon self-energy in massless QCD (`ExampleQCD`), verified against hep-ph/9801380
- 1- and 2-loop Higgs production through gluon fusion via a massive top loop (`ExampleHiggs`), verified against arXiv-hep-ph0611236v1
